# Kiosko App

Aplicación para gestión de inventario y ventas con lector de códigos QR y códigos de barras. Ideal para pequeños negocios y kioscos.

## Características principales

- **Escaneo de códigos QR y códigos de barras**: Utiliza la cámara para identificar productos rápidamente.
- **Gestión de inventario**: Controla tu stock, recibe alertas de productos con bajo inventario.
- **Procesamiento de ventas**: Crea carritos de compra y procesa ventas fácilmente.
- **Categorización por industria**: Organiza tus productos según el tipo de negocio.
- **Pagos con Mercado Pago**: Integración completa para procesar pagos por suscripción.
- **Interfaz simple y limpia**: Diseñada para ser fácil de usar sin elementos innecesarios.

## Requisitos técnicos

- Android 7.0 o superior
- Cámara trasera funcional
- Conexión a Internet para sincronización y pagos

## Planes de suscripción

La aplicación ofrece diferentes planes de suscripción que se adaptan a las necesidades de tu negocio:

- **Plan Básico**: Funcionalidades esenciales para negocios pequeños.
- **Plan Estándar**: Incluye más características y mayor capacidad.
- **Plan Premium**: Acceso completo a todas las funcionalidades.
